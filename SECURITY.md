# Security

This integration currently has no network server, credentials, custom authentication, or external notification transport. Its queries use Home Assistant's service interface and permissions. Snapshots may contain selected entity ids, integration ids, source names, states, and episode details; treat Home Assistant backups as private.

Report a security concern privately to the repository maintainer. Do not include access tokens, complete HA configuration, or private device traces in a public issue. There are no supported public releases yet.
