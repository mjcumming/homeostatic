# Homeostatic brand icon

The editable light and dark source files are `icon.svg` and `dark_icon.svg` here. Their exported PNGs are installed in `custom_components/homeostatic/brand/` so Home Assistant 2026.3 and later can show the integration's own icon. The mark combines a house, one central health signal, and two dependent nodes. It contains no Home Assistant branding.

The PNGs have transparent backgrounds. `icon.png` and `dark_icon.png` are 256 × 256 pixels; the `@2x` variants are 512 × 512 pixels. Re-export all four after changing the SVGs and check legibility at 24 pixels on light and dark backgrounds. The integration's existing panel glyph is a generic navigation symbol; these images are its actual installation brand assets.
